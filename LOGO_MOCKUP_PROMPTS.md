# Logo Mockup Prompts for W-AI

Simple prompts for generating logo mockups across different platforms. These prompts are designed to be minimal and let AI use its creativity.

## Brand Colors Reference

**Primary Colors:**
- `#1D4F34` - Forest Green (main brand)
- `#40916C` - Bright Green
- `#52B788` - Light Green
- `#B4D4C0` - Mint Green (accent)

**Gradient:** `#1D4F34` → `#40916C` → `#52B788`

---

## Base Template

```
[Platform/Context] showing W-AI logo. [Platform-specific details]. 
Forest green colors (#1D4F34 to #52B788). Clean, professional mockup.
```

## How to Use

1. **Copy a template** from the examples above
2. **Add platform-specific details** if needed (e.g., "dark mode", "light background", "small size")
3. **Generate** using your preferred AI image generator
4. **Iterate** by adjusting the platform details

## Adding New Platforms

Use this format:
```
[Platform Name]
[Platform/Context] showing W-AI logo. [Specific details about how logo appears]. 
Forest green colors (#1D4F34 to #52B788). Clean, professional mockup.
```

Keep it simple. Let the AI be creative with the visual details.
